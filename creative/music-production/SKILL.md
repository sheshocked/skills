## When to Use
Produce, mix, or arrange music for any context: songs, podcasts, videos, games, apps, or live performances. Covers production workflow, mixing fundamentals, arrangement, and sound design.

## Core Concepts
- **DAW (Digital Audio Workstation)**: Ableton Live (electronic/production), Logic Pro (Mac-native), FL Studio (beat-making), Pro Tools (industry standard mixing), Reaper (budget-friendly).
- **Signal chain**: Source → Preamp → EQ → Compression → Effects → Master. Understanding the signal flow prevents muddy mixes.
- **Mixing vs Mastering**: Mixing balances individual tracks. Mastering optimizes the final stereo file for distribution. Different skills, different stages.
- **Frequency spectrum**: Sub-bass (20-60 Hz), bass (60-250 Hz), mids (250-4k Hz), highs (4k-20k Hz). Each instrument lives in a frequency range.
- **Arrangement dynamics**: Verse-chorus-verse-chorus-bridge-chorus. Variation in energy keeps listeners engaged.
- **Reference tracks**: Always mix against a professional track in the same genre. Your ears adjust; references don't.

## Workflow
1. **Pre-production**: Write the song/idea. Demo with voice memo or basic sketch. Define the vibe, tempo, key.
2. **Tracking/Recording**: Record all source material. Vocals, instruments, samples. Get the best raw recording possible.
3. **Arrangement**: Build the structure. Add/remove elements to create dynamics. Every section should feel different.
4. **Mixing**: Balance levels, pan instruments, EQ for clarity, compress for consistency, add effects (reverb, delay).
5. **Mastering**: Final polish: EQ, limiting, loudness normalization (-14 LUFS for streaming).
6. **Distribution**: DistroKid, TuneCore, or CD Baby for streaming platforms. Spotify, Apple Music, YouTube Music.

## Key Patterns
```markdown
# Mixing Checklist
1. Gain staging: Set each track peaking around -12 dBFS before mixing
2. Panning: Place instruments in stereo field (kick/bass center, guitars 30-70%, pads wide)
3. EQ: Cut mud (200-400 Hz) before boosting. High-pass everything that doesn't need bass.
4. Compression: Vocals (3-4 dB reduction, 2-4ms attack), drums (fast attack, medium release)
5. Reverb: One main reverb bus for cohesion. Short for intimate, long for epic.
6. Volume automation: Ride vocal volumes. Automate chorus lifts.

# Arrangement Template (Pop/Electronic)
0:00-0:15  Intro (4-8 bars) — establish the vibe, no drums or minimal
0:15-0:45  Verse 1 (8 bars) — full instrumentation, storytelling
0:45-1:15  Chorus 1 (8 bars) — biggest section, catchy hook
1:15-1:30  Post-chorus / Instrumental hook (4 bars)
1:30-2:00  Verse 2 (8 bars) — variation from verse 1
2:00-2:30  Chorus 2 (8 bars) — add a new element
2:30-3:00  Bridge (8 bars) — contrast, build tension
3:00-3:30  Final Chorus (8 bars) — maximum energy
3:30-3:45  Outro (4 bars) — fade or hard stop

# Sound Design: Quick Synth Recipes
Pad: Saw wave + low-pass filter (cutoff 40%) + reverb (large hall) + slow LFO on filter
Bass: Square wave + sub oscillator + compression + subtle saturation
Lead: Square wave + high-pass filter + delay (1/8 note) + chorus
Pluck: Triangle wave + fast envelope on filter + reverb (plate, short decay)
```

## Pitfalls
- **Mixing too loud too early**: Start with everything quiet. Clipping at the mix stage creates unrecoverable distortion
- **Ignoring reference tracks**: Without a reference, your ears normalize to the mix. Compare every 15 minutes.
- **Too many effects**: Reverb on everything creates mud. Use effects intentionally, not decoratively
- **Not low-cutting**: Every track below 80 Hz that isn't kick/bass creates muddiness. High-pass filter everything else
- **Mixing on laptop speakers**: Use headphones or monitors. Check on multiple systems before finalizing
- **Not taking breaks**: Ears fatigue after 1-2 hours. Mix in 90-minute sessions with 15-minute breaks.

## Verification
- A/B test your mix against a reference track at matched loudness — does it sound comparable?
- Check on multiple systems: headphones, car speakers, phone speaker, Bluetooth speaker
- Solo each track: can you hear any issues (hiss, clicks, frequency buildup) when isolated?
- LUFS check: Target -14 LUFS integrated for streaming platforms
- Listen on a fresh day: mix sounds different with fresh ears — schedule final listen after sleep
