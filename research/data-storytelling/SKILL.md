## When to Use
Transform analysis into compelling narratives: framing, visual evidence, sequencing.

## Narrative Structure
1. **Hook**: Start with a surprising insight
2. **Context**: What's the situation?
3. **Conflict**: What's the problem/opportunity?
4. **Analysis**: What does the data show?
5. **Resolution**: What should we do?

## Data Presentation Rules
- **One chart = one message**: Don't overload
- **Lead with the insight**: "Revenue grew 40% YoY" before the chart
- **Label directly**: Put labels on data points, not in legends
- **Use color sparingly**: Highlight what matters
- **Source everything**: Where did this data come from?

## Chart Selection
| Data Type | Best Chart |
|---|---|
| Trend over time | Line chart |
| Comparison | Bar chart |
| Part of whole | Pie (max 5 slices) or stacked bar |
| Distribution | Histogram |
| Relationship | Scatter plot |

## Pitfalls
- **Cherry-picking**: Show the full picture, not just convenient data
- **Correlation ≠ causation**: Don't imply causation from correlation
- **Truncated axes**: Misleading — start at zero for bars
- **Too many charts**: 3-5 charts max per presentation

## Verification
- Can someone understand the key insight without the chart?
- Does the narrative flow logically?
- Are all claims supported by data?
