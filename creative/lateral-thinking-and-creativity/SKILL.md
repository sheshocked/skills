# Lateral Thinking & Creativity

Use this skill when designing features, mockups, UX animations, name branding, or brainstorming new product concepts.

## Creative Methodologies
1. **Concept Collision:** Force two unrelated concepts together (e.g., "What if our VPN client settings interface behaved like a physical retro audio mixer?") to discover unexpected visual or functional paradigms.
2. **Inversion Exercise:** Design for the exact opposite outcome. E.g., "How would we design this interface to make it as hard as possible to connect?" - analyze the result, and invert those pitfalls to find the ultimate clean workflow.
3. **Anti-Slop Validation:** Relentlessly audit designs for generic AI aesthetics (purple gradients, glowing outline boxes, meaningless icons) and inject raw, intentional design style (e.g., neo-brutalist, skeuomorphic, high-contrast minimal).
