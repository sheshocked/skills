## When to Use
Map a technology space: players, paradigms, maturity, adoption signals.

## Scan Framework
```markdown
# Technology Landscape: {Topic}

## Market Map
| Category | Players | Trend |
|---|---|---|
| Layer 1 | A, B, C | Growing |
| Layer 2 | D, E | Emerging |
| Layer 3 | F, G, H | Declining |

## Maturity Assessment
- **Emerging**: Novel, limited production use
- **Growing**: Increasing adoption, maturing APIs
- **Mature**: Stable, well-documented, large community
- **Declining**: Being replaced, limited maintenance

## Key Signals
- GitHub stars growth rate
- NPM/PyPI download trends
- Conference talks and blog posts
- Venture funding rounds
- Job posting frequency
```

## Pitfalls
- **Hype vs reality**: Distinguish genuine innovation from marketing
- **Recency bias**: Established tools may still be best
- **Vendor lock-in**: Evaluate portability
- **Community health**: Check issue response times, contributor diversity

## Verification
- Cross-reference multiple data sources
- Talk to practitioners, not just vendors
- Check production adoption stories
- Revisit quarterly — landscape changes fast
