# ArXiv Research Skill

Use this skill when the user asks to find academic papers, search arXiv, analyze scientific literature, or extract research methodology.

## Guidelines
1. Query arXiv using precise keywords, authors, or categories (e.g., cs.AI, cs.LG).
2. Summarize abstracts highlighting Key Findings, Methodology, and Limitations.
3. Extract and parse mathematical formulas or equations accurately.
4. Download and page through PDF files using ocr-and-documents when required.
