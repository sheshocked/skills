## When to Use
Track competitors: feature matrices, pricing monitoring, changelog analysis, positioning.

## Feature Matrix
```markdown
| Feature | Us | Comp A | Comp B | Comp C |
|---|---|---|---|---|
| Feature X | ✅ | ✅ | ❌ | ❌ |
| Feature Y | ✅ | ❌ | ✅ | ❌ |
| Pricing | $29/mo | $49/mo | $19/mo | $39/mo |
| Free tier | ✅ | ❌ | ✅ | ❌ |
| API access | ✅ | ✅ | ❌ | ✅ |
```

## Monitoring Tools
- **Visualping**: Monitor competitor websites for changes
- **Wayback Machine**: Track historical changes
- **Product Hunt**: Track new launches
- **Crunchbase**: Funding and growth data
- **Social media**: Monitor competitor mentions

## Pitfalls
- **Copying vs differentiating**: Learn from competitors, don't copy
- **Feature parity trap**: Don't try to match every feature
- **Pricing wars**: Compete on value, not price
- **Outdated data**: Competitor landscape changes fast

## Verification
- Update matrix monthly
- Verify claims with actual product testing
- Cross-reference multiple sources
