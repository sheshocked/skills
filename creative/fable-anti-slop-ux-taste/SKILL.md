# Fable 5 Anti-Slop UX Taste

Use this skill to guide Fable 5 when generating custom layouts, theme sets, or interactive micro-interactions.

## Design Framework
1. **Ditch AI Stereotypes:** Prevent Fable 5 from using generic layout patterns (e.g., standard cards with teal icons, glowing outer outlines, purple backgrounds).
2. **Establish Artistic Persona:** Instruct the model to adopt concrete design languages (e.g., Neo-Brutalist with flat solid borders, Skeuomorphic with glassmorphism, or INCY-inspired dark OLED navy).
3. **Refine Micro-Animations:** Design spring-based, physics-backed animations instead of simple linear transitions.
