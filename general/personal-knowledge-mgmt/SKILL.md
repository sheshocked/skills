## When to Use
Build personal knowledge management: note-taking systems, spaced repetition, capture workflows.

## PKM Systems
1. **Zettelkasten**: Atomic notes with links
2. **PARA**: Projects, Areas, Resources, Archives
3. **Daily Notes**: Journal-style capture
4. **MOC**: Maps of Content (topic index pages)

## Obsidian Workflow
```markdown
# Daily Note Template
## [[{{date}}]]

### Capture
- 

### Tasks
- [ ] 

### References
- [[related-note-1]]
- [[related-note-2]]

### Reflections
```

## Note Types
- **Fleeting**: Quick capture, process later
- **Literature**: Notes from reading
- **Permanent**: Refined, atomic ideas
- **MOC**: Index pages linking related notes

## Pitfalls
- **Over-organization**: Simple folder structure beats complex taxonomy
- **Collecting**: Process notes weekly
- **Link density**: Link to existing notes, don't create new ones for minor variations
- **Tool obsession**: Content matters more than tool

## Verification
- Can you find any note in <30 seconds?
- Do you regularly review and link notes?
- Is your system growing with you?
