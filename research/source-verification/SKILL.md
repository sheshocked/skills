## When to Use
Verify claims and sources: primary source checking, lateral reading, archive verification.

## Lateral Reading Technique
1. Leave the source
2. Open new tabs to search for the source/author
3. Check what others say about this source
4. Return to original with context

## Verification Checklist
- **Author**: Who wrote this? What are their credentials?
- **Source**: Is this primary or secondary?
- **Date**: When was this published? Is it current?
- **Evidence**: What supports the claims?
- **Bias**: What's the funding source? What's the agenda?
- **Corroboration**: Do other sources confirm this?

## Archive Tools
- **Wayback Machine**: web.archive.org — historical snapshots
- **Archive.today**: archive.today — save current page
- **Google Cache**: cached version of pages

## Red Flags
- Anonymous sources without corroboration
- Statistics without methodology
- Circular sourcing (source A cites source B which cites source A)
- Emotional language instead of evidence
- No date or author attribution

## Pitfalls
- **Confirmation bias**: Actively seek disconfirming evidence
- **Authority bias**: Credentials ≠ correctness
- **Social proof**: Popularity ≠ accuracy
- **Outdated information**: Verify currency

## Verification
- Can you find the primary source?
- Are multiple independent sources confirming?
- Is the methodology sound?
