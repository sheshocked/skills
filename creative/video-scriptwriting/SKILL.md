## When to Use
Write scripts for YouTube videos, TikToks, Reels, course modules, product demos, brand films, ad spots, or documentary segments. Covers long-form (10+ min) and short-form (15-60 sec).

## Core Concepts
- **Hook (0-3 sec)**: The first sentence determines if anyone watches. Use pattern interrupt, bold claim, or curiosity gap.
- **Retention curve**: Attention dips at predictable points. Place pattern interrupts (B-roll, graphics, jokes) every 30-60 seconds.
- **Retention editing**: Cut every breath, pause, and "um." Dead air kills retention. Match cuts to sentence rhythm.
- **B-ROLL planning**: Script calls for specific visuals. Don't leave B-roll as "TBD" — it becomes generic stock footage.
- **CTA placement**: Mid-roll CTAs (after value peak) outperform end-of-video CTAs by 2-3x.
- **Retention metrics**: YouTube measures audience retention percentage. Target 50%+ average view duration.

## Workflow
1. **Define the goal**: Education, entertainment, conversion, or brand building? Each requires different structure.
2. **Research hook**: Study top-performing videos in the niche. Note the first 3 seconds of each.
3. **Write hook first**: Test 10+ hooks. The best hook earns the right to write the rest.
4. **Outline with beats**: Map the emotional/attention arc before writing dialogue.
5. **Write dialogue**: Conversational. Short sentences. Read aloud — if it sounds stiff, rewrite.
6. **Add visual directions**: Every 10-15 seconds, specify what's on screen (B-roll, graphic, face cam, text overlay).
7. **Time it**: Read at natural pace. 150 words/minute for YouTube. 2.5 words/second for TikTok.

## Key Patterns
```markdown
# YouTube Video Script Template (10-min)

[HOOK - 0:00-0:03]
Bold statement or question. "You're wasting 3 hours a week on this."

[PRE-INTRO - 0:03-0:15]
Preview what they'll learn. "In this video, I'll show you..."

[INTRO - 0:15-0:30]
Channel branding (keep under 5 sec). Topic context.

[SECTION 1 - 0:30-3:00]
First major point. Pattern interrupt every 30 sec.
Mid-roll CTA: "If this is helpful so far, hit subscribe."

[SECTION 2 - 3:00-6:00]
Second point with demonstration/screen share.

[SECTION 3 - 6:00-8:30]
Third point. Most actionable/surprising content here (peak retention).

[RECAP - 8:30-9:30]
Summarize key points. Show visual recap card.

[OUTRO - 9:30-10:00]
End-screen CTA. "Watch this next video [point to card]."

# TikTok/Reel Script Template (30 sec)
[0-3s] HOOK: "Stop doing [common practice]."
[3-8s] PROBLEM: Why the common practice fails
[8-18s] SOLUTION: The better approach (show it, don't just tell)
[18-25s] PROOF: Quick result or stat
[25-30s] CTA: "Follow for more [topic] tips"

# B-Roll Direction Template
0:15 — B-ROLL: Close-up of hands typing on laptop (2 sec)
0:30 — GRAPHIC: Animated chart showing "Before vs After" data
1:00 — SCREEN SHARE: Show actual software interface
1:15 — B-ROLL: Walking through office (3 sec, sped up 2x)
```

## Pitfalls
- **Writing for the eye, not the ear**: Scripts read well but sound robotic. Always read aloud.
- **Front-loading value**: Saving the best for last loses viewers. Put strongest content in the middle.
- **No visual variety**: Talking head for 10 minutes tanks retention. Switch angles/shots every 15-30 sec.
- **Over-scripting**: Leave room for genuine personality. Bullet points beat word-for-word for personality-driven content.
- **Ignoring the first 3 seconds**: 70% of viewers leave in the first 10 seconds. Hook is non-negotiable.

## Verification
- Read the script aloud at natural pace and time it — does it hit target length?
- Hook test: Would you stop scrolling for this opening line? Test on 3 people.
- Retention check: Map attention peaks and valleys — is the strongest content where retention dips?
- B-roll completeness: Every scene has a visual direction. No "TBD" entries.
- CTA placement: At least one mid-roll CTA, not just at the end
