# Context Engineering & Compounding

Use this skill when concluding a session, transitioning between tasks, or organizing project documents.

## Guidelines
1. **Knowledge Compounding:** Capture key insights, decisions, and system patterns into a local `CONTEXT.md` file. Never let valuable debugging discoveries get buried in chat logs.
2. **Handoff Documentation:** Draft precise, bulletproof handover notes for subsequent agents, specifying exact paths, environment states, and the immediate next step.
3. **Prevent Context Drift:** Keep system prompts and instructions compact, high-signal, and free of redundant rules that waste context windows.
