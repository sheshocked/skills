## When to Use
Conduct user research: interviews, usability tests, surveys, persona development.

## Usability Test Script
```markdown
## Task 1: {scenario}
1. "Please show me how you would {task}"
2. Observe: time, errors, hesitation
3. "How was that experience?" (1-5 + open-ended)

## Post-task Questions
- What was confusing?
- What did you expect to happen?
- How does this compare to [alternative]?
```

## Survey Design Rules
1. Start with easy, non-sensitive questions
2. Use Likert scales (1-5 or 1-7) for attitudes
3. Include open-ended for qualitative insights
4. Avoid double-barreled questions
5. Test with 5 people before full launch

## Persona Template
```markdown
# Persona: {Name}
- **Role**: {Job title}
- **Goals**: {What they want to achieve}
- **Frustrations**: {Current pain points}
- **Tools**: {Current tools used}
- **Quote**: "{What they said}"
```

## Pitfalls
- **Leading questions**: "Don't you think this is easy?" → "How was that?"
- **Self-report vs behavior**: Watch what they do, not what they say
- **Recruitment bias**: Recruit representative users
- **Sample size**: 5-8 users per persona reveals 85% of usability issues

## Verification
- Test with real users, not colleagues
- Record sessions (with consent)
- Synthesize findings into actionable recommendations
