# Fable 5 Advanced Visual Debugging

Use this skill when auditing UI designs (such as INCY style layouts), verifying animations, or analyzing screenshots.

## Visual Auditing Protocols
1. **Pixel-Level Coordinate Extraction:** Leverage Fable 5's vision capability to isolate UI bugs (e.g., stacked text, overlapping borders) and output their exact coordinates [x, y] in the layout.
2. **Visual Contrast Comparison:** Audit text and background pairings against APCA/WCAG accessibility guidelines using image visual cues.
3. **Design Delta Analysis:** Compare a UI screenshot with its reference image (Figma mockup or AssA7778 style design) and list all layout discrepancies.
